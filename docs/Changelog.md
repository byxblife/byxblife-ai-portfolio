# Changelog

本文件用來記錄 `src/index.html` 每次版本更新的重點，方便之後快速知道改了什麼，也能回頭對照 git 紀錄。

## 使用方式

- 之後只要 `src/index.html` 有異動，就新增一筆版本紀錄。
- 若同一次更新同時改到 `src/style.css` 或 `src/script.js`，也建議一起寫進同一筆。
- 版本號建議規則：
  - `v1.0.1`：小幅文字、連結、圖片或細節調整
  - `v1.1.0`：新增一個區塊、互動或重要內容
  - `v2.0.0`：大改版、資訊架構重整、視覺方向明顯變更

## 更新欄位格式

| 日期 | 版本號 | 執行項目 | 變更內容概述 | Git 參考 |
| --- | --- | --- | --- | --- |
| YYYY-MM-DD | vX.Y.Z | 新增 / 編輯 / 刪除 | 用 1 至 2 句寫清楚這次改了什麼、影響哪個區塊 | commit hash / commit 訊息 |
